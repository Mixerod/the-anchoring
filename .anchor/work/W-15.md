# W-15: Layer 4 Part C: Promotion

## Goal

Implement Layer 4 Part C (`kb promote <INC-id> --to-pack <name>`):
- Pure domain promotion planner in `src/promote.ts` that converts an incident into a pack hazard.
- Strips local anchors (`holds_for: []`), local paths, and diffs/code excerpts.
- Sets `resolution: not-applicable` with `reason: not yet triaged in this repository` to avoid the 30-day clock / ceiling time bomb in adopting repos.
- Stable ID allocation: re-promoting the same incident returns the existing hazard ID and does not duplicate.
- CLI handler in `src/cli-promote.ts` supporting `--to-pack`, `--dry-run`, and `--source`.
- Promote repository incidents `INC-0001` and `INC-0002` into `templates/packs/discipline/hazard/`.
- Ensure `verify-hazard.ts` permits `holds_for: []` when `resolution === 'not-applicable'`.
